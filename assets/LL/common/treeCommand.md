# Tree Command Utility

## 1. What is the tree command?
The `tree` command is a CLI (Command Line Interface) tool used to display the contents of a directory in a tree-like format. It lists files and subdirectories recursively, making it easy to understand the organization of a project at a glance.

## 2. Installation
To install the utility on Linux (Debian/Ubuntu/WSL), use the following command:

```bash
sudo apt update && sudo apt install tree
```
